A sampling of smaller scale projects and side quests.

<div class="box" markdown="1">
[TinyLM:](https://github.com/guptbot/tinyLM) Brought to you by a curiousity to see how small language models can be while still producing coherent sentences. \[[code](https://github.com/guptbot/tinyLM)\]
</div>

<div class="box" markdown="1">
[K9DB:](https://github.com/brownsys/K9db) I collaborated on the development of an open source database system for GDPR compliance-by-construction. Halved memory overheads. Published at OSDI `23. \[[code](https://github.com/brownsys/K9db)\]
</div>

<div class="box" markdown="1">
[Free Will Lean:](https://github.com/guptbot/free_will_lean) Formalized the Kochen-Specker paradox using Lean 4. \[[code](https://github.com/guptbot/free_will_lean)\]
</div>

<div class="box" markdown="1">
**Spot Tour Guide:** A robotic tour guide that interacts with you while generating custom tours of a space. *Done as an intern project at the RAI Institute*
</div>

<div class="box" markdown="1">
[Fixing Option Critic:](#) Came up with all kinds of complex solutions to prevent the option-critic algorithm from suffering options collapse. Then realized you only need to add another hyperparamer to the loss function \[[writeup](#)\] \[[code](https://github.com/guptbot/hierarchical-policy-learning)\]
</div>

<div class="box" markdown="1">
[Deforming objects:](#) An (unsuccessful) attempt to get Dramer V3, PlaNet and PPO to work on benchmarks involving deformable objects while operating in pixel space.
[[code](#)\]
</div>

<div class="box" markdown="1">
[Spot Object Manipulation:](https://github.com/guptbot/spot-object-manipulation) A codebase enabling spot to scan, map and interact with objects in an environment.[[code](https://github.com/guptbot/spot-object-manipulation)\]
</div>

<div class="box" markdown="1">
[Hierarchical planning:](https://github.com/SergioMOrozco/multi_level_planning) A heuristic-based algorithm to quickly generate task plans given a hierarchy of action abstractions. [[code](https://github.com/SergioMOrozco/multi_level_planning)\]
</div>

<div class="box" markdown="1">
[Airstrument:](https://github.com/Aubrey-Li/motion-instrument) A arduino based watch. You wave your hands, music plays. [[code](https://github.com/Aubrey-Li/motion-instrument)\]
</div>

<div class="box" markdown="1">
[Karnaugh Maps:](https://github.com/guptbot/karnaugh-maps) Engineering homework had too many Karneugh map questions. So I wrote a script to do my homework for me [[code](https://github.com/guptbot/karnaugh-maps)\].
